Part 3 — naming a tab that holds several panes

Read this before picking: a tab is exactly 160px, always. TAB_WIDTH = 160 in TabBar/utils/utils.ts. After the 12px left pad, the count badge, the gaps and the 28px box the dot and close button share, the title gets about 96px — roughly 13 characters at 12px before it starts fading. "GatedKey" alone is 8. That single number decides most of what follows.

As shipped — D + N3/N4, icon kept

He picked D ("keep the icon, and always have the icon") and N4 — N3. Built on 2026-08-17. What changed from the options above:

  • Tabs had no icon at all before this. renderTabIcon returned a favicon for single-browser tabs and null for everything else — the registry's getIcon only ever drew the pane header. So "always have the icon" needed a new getTabIcon(pane) on the registry, implemented for all eight pane kinds.
  • It takes a pane, not a RendererContext, because a tab has no rendered pane behind it — no actions, no store binding, no isActive. Every getIcon happens to read only context.pane today, but faking the rest of a context to reuse it would break the first definition that reached for actions, and only in the tab bar.
  • The hover card is portaled. The tab strip is overflow-x-auto overflow-y-hidden, so a plain absolutely-positioned popover — which is what the preview above uses — would have been clipped to the 40px bar and shown nothing.
  • Clicking a row calls setActiveTab and setActivePane. Being portaled means a click in the card never reaches the tab's own handler, so without the first call you would focus a pane inside a tab you are not looking at and nothing on screen would move.
  • Rows are listed in layout order, not Object.keys(tab.panes) order. The record keeps insertion order, which stops matching the screen as soon as a pane is moved — and a numbered list that disagrees with what you are looking at is worse than one with no numbers.
  • An unknown pane kind still renders a neutral outlined square, so the badge always has something to sit on rather than floating on its own.
