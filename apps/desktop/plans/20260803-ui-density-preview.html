2 · The missing fade on Edit / Write

Bash fades because its body sits on the page background. A diff paints its own surface, so the existing fade class would blend to the wrong colour — which is why it was left off rather than forgotten. The fix is a fade that matches the diff surface, so a clipped edit reads as clipped instead of chopped.

3 · The pinned prompt

Today it clamps at 2 lines with a 16px fade and a text "Show more". You asked for 3 lines, a fade that signals there's more, and click-to-expand. Clicking already works — it's just not obvious.
