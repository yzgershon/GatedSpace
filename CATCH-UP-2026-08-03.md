Three specific things to internalise:

- **Never import electron at module scope in anything a child entrypoint can
  reach.** The five that run as plain Node are `host-service`, `terminal-host`,
  `pty-daemon`, `pty-subprocess`, `git-task-worker`. Use a lazy
  `require("electron")` inside a function — the idiom is already in
  `git-task-runner.ts` and `native-permissions.ts`. One static import is fatal
  app-wide because rollup hoists an external dep into every chunk that reaches
  it; one import became a top-level `require("electron")` in six chunks.
  `validate-native-runtime` now fails the build on this and names the chunk.

- **When the host service misbehaves, the main log is not enough.** It only
  says "host service prewarm failed". The child's real error is in

  installed.** The NSIS installer half-installs over a running app and reports

  fix looks broken. This cost about an hour. Check the installed version and
  compare the mtimes of `GatedSpace.exe` and `app.asar` against the DLLs beside
